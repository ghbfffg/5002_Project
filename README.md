# 纽约黄色出租车司机生存指南

本项目用 2013 年 4 月的司机与车辆记录研究一趟车占用多少工作时间、下车后多久能接到下一单，再用 2024 年 12 月和 2025 年 1 月的信用卡记录研究行程相对用时与小费的关系。两期数据各自回答对应的问题。

运行项目可生成 A0 横版海报及预览图。[详细分析](Analysis.md) 给出了清洗流量、完整分组结果、敏感性检查及图表。

## 研究问题与计算口径

| 问题 | 如何计算 | 海报上的发现 |
|---|---|---|
| 从中城去 JFK，机场车费能补回送客后的空档吗？ | 在相同上车区、日期和出发小时比较机场与曼哈顿市内单。按同小时机场单数给市内组加权。周期小时车费为基础车费合计除以载客与单后间隔的总小时数。主分析只纳入 90 分钟内有下一笔同车同司机上客记录的行程。 | 工作日 16–20 时，JFK 为 30.32 美元/小时，市区为 33.64 美元/小时。时间尺显示机场单持平所容许的平均间隔为 40.4 分钟，观测均值为 50.6 分钟。 |
| 热门街区送完客，能更快续单吗？ | 按上车区计算平均每小时成交数，按下车区计算送客后五分钟内同车同司机再次上客的比例。分母包含未观察到下一单的送达，下一单可以发生在其他区。 | Yorkville East 的五分钟续单率从工作日早晨的 86.2% 降到周末凌晨的 31.5%。East Village 同期从 78.5% 升到 86.6%。 |
| 建议比例小费能反映一趟车开得慢吗？ | 计算实际用时相对于同日、同小时、相似距离组中位用时的倍数。分别汇总小费金额与建议比例吻合组、其他金额组的小费率，再限制账单范围比较美元金额。 | 从较快到极慢，其他金额组的平均小费率从 14.26% 降到 10.26%，吻合组从 20.31% 变为 20.51%。19 美元账单的付款面板演示同一金额可以对应不同体验。 |

工作日早晨为 07:00–09:59，周末凌晨为 00:00–02:59。单后间隔可包含空驶、排队或休息。基于金额识别的建议比例匹配只能说明付款结果，乘客满意度和真实按钮选择需要独立观测。天气、人数和供应商分层结果收录于分析报告。

## 清洗与处理

1. **司机样本。** 两张 2013 年原表各有 15,100,468 行。按司机标识拆分文件以控制内存，使用全部分区。以司机、车辆、供应商和上车时间作联合键，仅保留完整唯一键并执行一对一配对。依次限制上车月、现金或信用卡、基础车费 2.5–300 美元、时长 1–180 分钟和距离 0.1–100 英里。最终有 14,891,164 笔、33,001 个司机标识。筛选流量（`tables/driver_flow.csv`）
2. **下一单。** 在去重后的司机原始时间序列中先确定紧邻的下一次上客，核对车辆相同，再筛选本单并计算地理分组。固定 Midtown Center 上车。机场对照覆盖 JFK 与 LGA，市区对照合并曼哈顿长短途。比较 30、60、90、120 分钟窗口及其覆盖数。街区分析另按 5、10 分钟续单统计。同小时对照（`tables/matched_cycles.csv`） · 按下车区续单（`tables/dropoffs.csv`）
3. **小费样本。** 限定上车日期属于相应月份、刷卡支付、基础车费大于 2.5 美元、时长大于 1 且小于 180 分钟、里程大于 0.5 且不超过 100 英里。小费前账单等于总额减小费，要求正账单，小费率范围为 0% 至低于 200%。保留零小费记录。相对用时参照组至少 30 笔，最终有 4,843,624 笔。逐月清洗流量（`tables/tip_flow.csv`）
4. **小费分组。** 实收小费与小费前账单的 15%、20% 或 25% 相差不超过 3 美分，即归为吻合。按五档相对用时比较，并在 18 至低于 20 美元账单中复核。另按月、供应商、匹配容差与天气复核，按日重抽 3,000 次估算差值区间，随机种子为 20261119。分组主表（`tables/tips.csv`） · 固定账单（`tables/fixed_bill.csv`） · 重抽区间（`tables/tip_intervals.csv`）

## 代码与产物

| 阶段 | 脚本 | 主要输入 → 输出 |
|---|---|---|
| 司机清洗与汇总 | [driver.py](code/driver.py) | 2013 行程、收费、区界、逐日天气 → 司机筛选、路线、时空和续单表，以及工作目录中的 routes.parquet |
| 小费清洗与汇总 | [tips.py](code/tips.py) | 两个月行程与小时天气 → 小费筛选、金额及比例分组、敏感性和区间表 |
| 同时段路线比较 | [compare.py](code/compare.py) | routes.parquet → matched_cycles.csv，含实际间隔、持平间隔及小时车费 |
| 报告图形 | [figures.py](code/figures.py) | 汇总表及区界 → figures/ 下 8 张图，含热图、地图、条形图和小费曲线 |
| 演讲海报 | [poster.py](code/poster.py) | 计算生成的汇总表 → Poster.pdf、Poster-preview.png |

海报的观测图由汇总表绘制，说明文字按这版数据撰写。更换研究月份时，还应复核海报文字。

## 复算

在仓库根目录执行。验证环境为 Python 3.12.8，所用主要库版本见 [requirements.txt](requirements.txt)。新建环境可使用以下命令。

```sh
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

从原始文件生成全部汇总表、报告插图和海报。将示例路径换成数据实际位置。`--work` 用于存放中间分区和逐单路线文件。

```sh
python run.py --data "/path/to/5002_project" --work "./work"
```

仅修改海报时，在完成全量复算后可复用本地汇总表，重新生成 PDF 和预览。单阶段命令依赖上表列出的输入。

```sh
python run.py --stage poster
python run.py --help
```

本次通过 [run.py](run.py) 完整运行五个阶段，将重新生成的 24 份 CSV 与代码整理前的版本逐文件对照，内容全部一致。PDF 为单页 A0 横向，已渲染检查文字、图例、坐标和付款面板。
